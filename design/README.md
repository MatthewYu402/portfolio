# Design reference

`red-slash.html` is `Main.dc.html` from the "A — Red Slash" mockup export.
It is a reference for layout, type, colour and panel shapes, not production code.
Any `{{accent}}` placeholder means `#C8102E`. The export's runtime (`support.js`, `vendor/`)
is not included, so the file won't render on its own; open the original zip to view it.
